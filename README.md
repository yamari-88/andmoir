# MOIR 2027 — сайт-концепт

Статичный сайт: HTML + CSS + JS, без сборки и библиотек. Работает локально (двойной клик по `index.html`)
и на любом статичном хостинге (GitHub Pages, Netlify, Cloudflare Pages: загрузить папку целиком).
Шрифты подтягиваются с Google Fonts, нужен интернет.

```
index.html        главная
collection.html   коллекция (бирки, LOOK)
product.html      FITTING ROOM  (?id=black-dress | leather-coat | leather-skirt)
bag.html          BAG
contact.html      контакты
css/style.css     все стили; цвета, шрифты, прозрачности лежат в :root в начале файла
js/products.js    товары: названия, цены, тексты, текст про доставку, сцены товаров
js/app.js         сумка (localStorage) и эффекты
assets/           все картинки (уже разложены)
```

## Шрифты
- Montserrat: логотип и MOIR на главной/контактах
- Momo Trust Sans: меню, заголовки, тексты, названия, Remove, сумка
- Mona Sans: LOOK, BUY, CHECKOUT, EMAIL US, размеры

## Кнопки
Заливка `#600000`, поверх `tape.png` с прозрачностью 5%, белая обводка 1px внутри (`.btn` в `style.css`).

## Эффекты
- Качание бирки: всегда слабое, при наведении сильнее (коллекция, сумка).
- Падение бирки при Remove (сумка).
- Трещины в зеркале: клик по зеркалу на странице товара и на контактах; каждый клик добавляет новую «паутину» поверх готовых трещин.
- Призрак за курсором: силуэт `sil-fitting.png` лениво тянется за мышью. Отключён на телефонах и при «уменьшить анимацию».

## Что заменить перед публикацией
- Почта: `meandmymoir@moir.example` в `contact.html`. Это зарезервированный домен-заглушка, письма на него не дойдут.
- Instagram и телефон на контактах: обычный текст, не ссылки.
- Текст про доставку: `deliveryText` в `js/products.js`.
- CHECKOUT ничего не оформляет, показывает пометку «Concept project».

## Как подправить
- Положение слоёв на странице товара: `scene` в `js/products.js` (проценты от поля 740×900).
- Положение скотча LOOK на бирках: `tag.tape` там же.
- Прозрачность толпы, тени за товаром, призрака, скотча: переменные в `:root`.
